Planday Bulk Employee Update Tool: Update employee details in bulk from Excel files or Table

This is an independent, open-source community project, not built or endorsed by Planday. It connects to your Planday portal via the official Open API (https://openapi.planday.com), processes all data locally on your device, and transmits it via a secure encrypted connection. The tool is provided "as-is" with no active maintenance, support, or updates. Use at your own discretion and responsibility.
